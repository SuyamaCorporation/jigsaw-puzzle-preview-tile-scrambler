# Jigsaw Puzzle Tile Scrambler Game

A numbered-tile sliding/swap puzzle where colored tiles (1–N²) are scrambled across a grid; click any two tiles to swap them and restore the correct numerical order. Supports three difficulty tiers (3×3, 4×4, 5×5), with a move counter, live timer that starts on your first move, and a running count of correctly-placed tiles.

A ghost-preview toggle dims misplaced tiles so the solved pattern is visible as a guide, a shuffle button resets the board without starting a new game, and your best move count per grid size is persisted to localStorage alongside in-progress game state.
